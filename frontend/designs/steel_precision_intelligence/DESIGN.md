## Brand & Style

This design system embodies high-precision knowledge intelligence: analytical, clear, and uncompromising in functional utility. Drawing inspiration from modern technical tooling and structural data architecture, the aesthetic balances modern enterprise durability with clean, disciplined minimalism.

### Persona & Atmosphere
- **Analytical & Precise:** Surfaces feel engineered rather than decorated. Information density is prioritized with structured typographic cadence and crisp boundaries.
- **Lucid Restraint:** Interfaces replace loud colors with a clean white canvas, disciplined neutral cool grays, deep slate typography, and targeted Steel Blue accents.
- **Tactile Utility:** Micro-interactions are rapid and responsive. Hairline borders, precise focus rings, and structured grids offer immediate tactile confidence.

### Style Archetype
- **Modern Structured Utility:** Defined by 1px hairline borders, monochromatic cool gray canvas tiers, pure white primary containers, tabular data alignment, and Steel Blue operational highlights.

## Colors

The palette establishes an information-first hierarchy using a clean white canvas, neutral cool gray surfaces, deep navy/slate typography, and targeted Steel Blue operational markers. All former green and teal accents are eliminated.

### Surfaces & Backgrounds
- **Primary Workspace / Main Canvas:** `#FFFFFF` — Default clean workspace backdrop, document views, and core card surfaces.
- **Surface Subdued / Shell:** `#F8FAFC` — Subtle panel backgrounds, table striping, and outer layout wrappers.
- **Surface Hover / Segmented Controls:** `#F1F5F9` — Pill tags, chips, badges, button hovers, and table row interactions.
- **Surface Elevated:** `#E2E8F0` — Active segmented toggles, structural dividers, and crisp perimeter strokes.

### Typography & Ink
- **Text Primary (Deep Navy/Slate):** `#0F172A` — Primary headings, high-contrast titles, and active query matches.
- **Text Secondary (Slate Dark):** `#334155` — Field labels, narrative body text, chip labels, and secondary actions.
- **Text Muted:** `#64748B` — Meta tags, timestamps, breadcrumbs, and table column headers.
- **Text Subtle:** `#94A3B8` — Disabled text states and non-actionable iconography.

### Structural Lines & Borders
- **Border Subtle (Default):** `#E2E8F0` — Default component contours, card boundaries, table grid lines, and chip strokes.
- **Border Strong:** `#CBD5E1` — Input borders, elevated element perimeters, and active selection frames.

### Accent & Active States
- **Primary Accent (Steel Blue):** `#0284C7` — Primary buttons, active tabs, focus indicators, selection badges, and active state highlights.
- **Primary Accent Hover:** `#0369A1` — Hover and pressed states for primary interactive elements.
- **Subdued Accent Fill:** `#E0F2FE` — Soft selection backgrounds, active search highlight pills, and tree node highlights.

## Typography

The typographic hierarchy prioritizes scanning speed, structural clarity, and baseline alignment across complex analytical views and split-pane layouts.

- **Typeface Families:** `Inter` serves as the primary system face across display, body, and label roles. Technical strings, citations, and metadata hashes use `JetBrains Mono`.
- **Tabular Numerics:** All numeric readouts, tables, and telemetry counters must activate `font-feature-settings: "tnum" 1, "cv05" 1, "cv11" 1` to guarantee rigid column alignment.
- **Ink Application:** Apply `#0F172A` to display and headline roles. Apply `#334155` to long-form body summaries and input values. Apply `#64748B` to peripheral metadata and column headers.

## Layout & Spacing

Layout geometry follows an 8px rhythm with a 4px sub-grid for compact UI nodes like pill tags, badges, and inline buttons.

### Layout Architecture
- **Multi-Pane Workspace:** Built for a three-pane desktop shell: a collapsible navigation rail (240px default / 64px collapsed), a fluid primary workspace (min 560px), and an evidence inspection panel (360px–480px).
- **Grid Integration:** 12-column fluid grid system utilizing `gutter` (16px) on compact viewports and `gutter-md` (24px) on wide viewports.
- **Reading Boundaries:** Data tables and multi-card grids span full workspace width up to 1440px; analytical syntheses and document readers constrain text to 768px for readable line lengths.

### Breakpoints & Reflow
- **Desktop (>= 1280px):** Three-pane layout displayed concurrently with persistent navigation and active evidence panel.
- **Tablet (768px - 1279px):** Navigation tucks into a collapsible dock or overlay drawer; contextual panel slides over workspace.
- **Mobile (< 768px):** Single-column stacked layout with top app bar navigation and bottom-sheet inspectors.

## Elevation & Depth

Visual hierarchy relies on flat structural planes, crisp 1px borders in `#E2E8F0`, and restrained ambient shadows rather than intense depth.

### Surface Hierarchy
- **Layer 0 (Canvas):** `#FFFFFF` — Primary application background and default canvas.
- **Layer 1 (Subdued Surfaces / Inset Panels):** `#F8FAFC` — Panel frames and container troughs with `#E2E8F0` hairline separation.
- **Layer 2 (Floating Popovers / Toolbars):** `#FFFFFF` paired with 1px border (`#E2E8F0`) and subtle ambient shadow: `0 4px 12px -2px rgba(15, 23, 42, 0.05), 0 2px 4px -1px rgba(15, 23, 42, 0.03)`.
- **Layer 3 (Modals / Global Command Palettes):** `#FFFFFF` paired with 1px border (`#CBD5E1`) and depth shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`. Scrim overlay uses `rgba(15, 23, 42, 0.35)`.

### Focus & Selection Rules
- Card hovers remain flat; they transition border color from `#E2E8F0` to `#CBD5E1`.
- Interactive elements express active focus states using a dual-ring boundary: `0 0 0 1px #FFFFFF, 0 0 0 3px #0284C7`.

## Shapes

The design system maintains a clean, structured geometry with soft corner definitions that reinforce technical utility.

- **Sharp Contours (0px):** Full-bleed table headers, split-view dividers, and outer frame docks maintain zero radius for architectural alignment.
- **Base Elements (4px / `rounded-sm`):** Inputs, primary buttons, citation markers, checkboxes, and inline controls.
- **Containers & Surfaces (8px / `rounded-lg`):** Cards, modal windows, floating command bars, and dropdown menus.
- **Pill Elements (9999px / `rounded-full`):** Badges, tag chips, and status pills strictly retain full pill curvature.

## Components

### Buttons
- **Primary Button:** Background `#0284C7`, text `#FFFFFF`, font weight 500, border radius 4px (`rounded-sm`). Height 32px (compact) or 36px (standard). Hover: `#0369A1`. Active: `#075985`. Focus ring: 3px `#0284C7` with 1px white offset.
- **Secondary / Outline Button:** Background `#FFFFFF`, 1px border `#E2E8F0`, text `#334155`. Hover: background `#F8FAFC`, border `#CBD5E1`. Active: background `#F1F5F9`.
- **Ghost Button:** Transparent background, text `#64748B`. Hover: background `#F1F5F9`, text `#0F172A`.

### Pill Tags, Badges & Chips
- **Neutral Chips & Pill Tags:** Full pill radius (`rounded-full`), background `#F1F5F9`, 1px border `#E2E8F0`, text `#334155` (`label-md` or `label-sm`), vertical padding 2px, horizontal padding 8px to 10px.
- **Active / Selected Chip:** Background `#E0F2FE`, 1px border `#0284C7`, text `#0284C7`, font weight 500.
- **Status Badges:** Pill-shaped (`rounded-full`), 1px border, padding `2px 8px`.
  - *Success:* Background `#F0FDF4`, border `#BBF7D0`, text `#15803D`.
  - *Warning:* Background `#FFFBEB`, border `#FDE68A`, text `#B45309`.
  - *Error:* Background `#FEF2F2`, border `#FECACA`, text `#B91C1C`.

### Input Fields & Controls
- **Text Inputs:** Height 36px, background `#FFFFFF`, 1px border `#E2E8F0`, radius 4px (`rounded-sm`), text `#0F172A`, placeholder `#94A3B8`. Hover: border `#CBD5E1`. Focus: border `#0284C7`, box-shadow `0 0 0 3px rgba(2, 132, 199, 0.15)`.
- **Checkboxes & Radios:** Size 16x16px, 1px border `#CBD5E1`, background `#FFFFFF`. Active / Checked: background `#0284C7`, border `#0284C7`, white glyph.

### Cards & Structured Surfaces
- **Evidence & Summary Cards:** Grounded on `#FFFFFF` with 1px border `#E2E8F0`, corner radius 8px (`rounded-lg`), padding `1rem`. Zero elevation by default. Hover: border `#CBD5E1`.
- **Card Highlights:** Keywords and search citations highlighted using background `#E0F2FE` with text `#0369A1`.

### Lists & Tables
- **Table Headers:** Height 36px, background `#F8FAFC`, bottom border 1px `#E2E8F0`, text uppercase `label-sm` in `#64748B`.
- **Table Rows:** Height 44px, background `#FFFFFF`, bottom border 1px `#F1F5F9`, text `#0F172A`. Hover: background `#F8FAFC`. Selected row: background `#F0F9FF` with a 2px left border in `#0284C7`.

### Navigation
- **Workspace Navigation Items:** Height 32px, radius 4px, text `#64748B`. Hover: background `#F1F5F9`, text `#0F172A`. Active state: background `#F1F5F9`, text `#0284C7`, font weight 500, with a 2px left indicator in `#0284C7`.
